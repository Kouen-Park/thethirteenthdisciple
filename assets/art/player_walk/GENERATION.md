# Player walk generation record

The original exact generation prompt and model metadata were not recoverable. The current eight directional PNG sheets are the authoritative runtime assets.

Each direction contains four equal frames: contact, passing, opposite contact, opposite passing. Body height and foot baseline remain fixed; mirrored directions must not change costume details. Runtime animation advances by distance and stops when movement is blocked.

Status: runtime-support; traversal and presentation tests are authoritative; human 1× silhouette review pending.
