# 전체 플레이 다듬기 · 2026-09-11

기존 이야기, 장 순서와 저장 ID를 유지하면서 탐색 중의 정보 확인, 입력 복구, 읽기와 연출을 다듬었다. 새 배경 생성 없이 기존 아트디렉션과 자산을 사용한다.

## 플레이어에게 달라진 점

- **기록 수첩**: 1–6장 탐색 중 `J` 또는 오른쪽 위 버튼으로 연다. 이전에 방문한 장의 관찰·증언·선택을 읽을 수 있다. 새 관찰은 제목과 전체 대사를 기록하며 예전 저장도 읽는다. `J`/Esc로 닫고, 긴 페이지는 마우스 휠 또는 PgUp/PgDn으로 스크롤한다. 대화·퍼즐·선택·연출 도중에는 열리지 않는다.
- **안내**: 목표와 E 프롬프트에 어두운 읽기 바탕을 적용한다. 4–6장은 숫자만 표시하던 목표 대신 남은 조사 대상을 안내한다. 수첩에 새 기록이 생기면 짧게 알려 준다.
- **조사와 조작**: 현장 조사 중 수첩을 열었다 닫아도 조사 기록과 이동 상태를 유지한다. 성찰 선택지의 키보드 초점을 내부에 유지하며 글자 크기 설정을 반영한다. 재사용 가능한 동전·천 조작 화면은 다음 사용 가능한 대상에 초점을 옮기고, 다시 열 때 원래 위치로 복원한다.
- **월드 표현**: 조사물을 비정수 비율로 확대하던 강조를 색과 작은 위치 변화로 정리했다. 3–6장 NPC 발밑에 작은 충돌 영역을 추가하고 숨은 인물과 떠난 인물의 충돌을 해제한다. 대화 때 주인공이 상대를 바라본다. 후반부 인물은 시간차를 두고 퇴장하며 6장의 낯선 이에게 카메라를 맞춘 뒤 탐색 시점으로 복귀한다.
- **메뉴**: 본편과 같은 성문 배경을 사용한다. 장면 선택의 임시 안내를 실제 장 내용으로 바꾸고 현재 진행 장에 초점을 둔다. 환경음·효과음 슬라이더의 수치를 표시하고 설정창을 연속으로 닫을 때 전환이 중복되지 않게 했다.
- **에필로그**: 글자 크기 설정을 반영한 중앙 회상 패널과 진행 표시, 즉시 전체 표시, 반복 키 입력 방지, 계속 읽는 동안의 바람 루프, 나갈 때 화면·음량 페이드를 적용했다.
- **입력·소리**: 나가기 취소가 다른 진행 잠금을 해제하거나 오래된 잠금을 남기지 않는다. 말풍선이 열린 채 장면을 떠나도 환경음 덕킹이 복구되며, 대화 중 음량을 바꿔도 새 설정을 기준으로 돌아온다.
- **같은 자리에서 쉬기**: 1–6장과 에필로그에서 `P` 또는 왼쪽 위의 잠시 멈춤 버튼을 사용한다. 대사·퍼즐·연출·움직임이 멈추고, 전체 음량·환경음·효과음과 대사 속도를 조절한다. `P`/Esc 또는 계속 버튼으로 같은 상태에서 이어가며 이전 퍼즐 버튼의 초점도 복구한다. 설정은 저장하지만, 이 기능은 장면을 닫거나 게임을 종료한 뒤의 중간 위치 저장은 아니다.
- **가까운 대상 고르기**: 근접한 인물과 조사물 사이에서 작은 움직임만으로 E 안내가 바뀌지 않도록 8px의 선택 여유를 둔다. 거리가 비슷하면 아직 읽지 않은 대상을 우선하고, 사라지거나 비활성화된 대상을 E로 실행하지 않는다.

## 검증

- 현장 조사 구조로 바뀌기 전에는 기존 스토리·1장 연출·2장·3장·후반부 9개 선택 경로 전체 진행 테스트를 통과했다. 새 인물 충돌로 인해 막히던 후반부 자동 이동을 길 가장자리 경유로 수정했다. 현재 별도 작업 **성경 기준으로 게임 전반 개선**에서 장 시작 설명과 현장 조사 구조를 변경하고 있어, 기존 전체 진행 테스트의 결과를 현재 빌드의 통과 근거로 사용하지 않는다.
- `tests/run_polish_tests.gd`: 수첩 잠금과 J 입력, 전체 대사 기록, 현장 조사 중 수첩 조회와 진행 보존, 나가기와 조사 잠금 분리, 장면 제거와 음량 변경 후 덕킹 복구, 동전·천의 키보드 초점 및 재시작 위치, 큰 글자 에필로그와 반복 환경음.
- `tests/run_pause_tests.gd`: 7개 장면에서 실제 P/Esc 입력으로 정지·복귀, 성경 배경 설명·대사·현장 조사 안내 시간의 정지, 조사한 행동과 손에 든 물건 보존, 활성 말풍선의 속도 변경, 정지한 장면 제거 시 처리 복구를 확인한다. 사용자 설정이나 저장 파일에 쓰지 않는다.
- `tests/run_traversal_tests.gd`: 물리 충돌로 보행 가능한 공간을 조사해 각 조사 대상에 접근하는 길을 확인하고, 실제 이동 입력으로 6개 월드를 가로지른다. 1장에서는 군중과 가장자리 건축물을 돌아가는 경로를 사용한다. 가까운 두 대상의 선택 유지·전환, 숨은 대상 제외, E 직전에 비활성화된 대상 보호도 확인한다.
- `tools/capture_polish.gd`: 실제 Godot 렌더러에서 메뉴·설정·장면 선택·월드·수첩·일시정지·현장 조사·성찰·큰 글자·에필로그·크레딧을 `output/polish/`에 캡처한다. 1280×720 및 1600×900 화면과 글자 배율 1.3을 확인한다. `-- wide` 인수로 1600×900 캡처를 재현한다. `puzzle`·`large-text` 이름의 이전 캡처는 교체 전의 버튼 퍼즐을 보여 주며, 현재 조사 화면은 `field-investigation`·`large-field`이다.
- `tools/run_polish_regressions.sh`: 공유 사용자 저장 경로를 사용하는 기존 테스트들을 순서대로 실행한다. 새 테스트는 저장 파일을 쓰지 않고 메모리 상태를 복원한다.
- `output/.gdignore`: 검증용 화면 캡처가 게임 자산으로 자동 임포트되지 않게 한다.

현장 조사 통합 후 `run_pause_tests`, `run_polish_tests`, `run_traversal_tests` 세 검증은 모두 실패 0으로 통과했다. 7개 장면의 정지·복귀와 6개 월드의 실제 이동을 포함하며, 큰 글씨 설정의 일시정지 화면도 확인했다. `FieldInvestigation._mark_done`에서 반환값이 없는 `queue_redraw()`를 삼항식으로 사용하던 실행 오류를 수정했다.

전체 NPC 보행 스프라이트 확장, 사람을 대상으로 한 난이도·플레이 시간 측정, 헤드폰/스피커 최종 음향 청취는 이번 자동 검증 범위에 포함하지 않는다.
