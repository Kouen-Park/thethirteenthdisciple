# 제3장 · 기다림 뒤에 남은 발소리

기준: ‘1, 2장 검토 및 개발 계획 수립’의 결합형 3장 계획, `assets/art/ART_DIRECTION.md`.

## 플레이 흐름

1. 늦은 오후: 우물·남겨진 천과 물그릇·미리암을 순서에 관계없이 조사한다. 요나와 지친 여행자는 선택 증언이다.
2. 해질녘: 필수 관찰을 마치면 빛이 바뀐다. 우물 앞의 기다리는 자리에서 E를 눌러 밤으로 넘긴다. 실제 시간 동안 기다릴 필요는 없다.
3. 밤: 같은 배경에서 문이 잠기고, 낮의 사람들이 떠나며, 등불·끌린 흔적·신발·청년이 나타난다. 세 흔적과 미리암/요나 중 한 사람의 증언이 필요하다. 문과 청년, 경비의 친척, 나머지 증인은 선택 조사다. 경비의 친척은 체포를 질서 회복으로 보는 상반된 의견을 들려준다.
4. 길목: 세 개의 등불 빛을 회전시켜 고정된 기름 자국 방향과 연결한다. 근거는 앞서 조사한 오른쪽→담에서 위쪽→다시 오른쪽 방향이다. 흔적을 움직이거나 사건을 복구하지 않는다.
5. 재판장 길: 소리를 따라감 / 거리를 두고 지켜봄 / 달아나는 청년을 도움. 선택을 취소하고 더 탐색할 수 있다. 선택 후에는 거리 이동 또는 청년의 퇴장으로 행동 차이를 남긴다.
6. 재판장 길을 다시 조사하면 출구 이동으로 장을 마친다. 4장 탐색형 재판장으로 이어진다. 후반부 구현으로 출시 실행에서도 에필로그까지 연속 진행할 수 있다.

조작: WASD/방향키 이동, E 조사, Space 대사 진행. 퍼즐은 Tab/방향키로 버튼을 선택하고 Enter/Space로 회전·확인한다. 마우스도 지원한다. Esc는 퍼즐/선택을 먼저 닫고, 탐색 중에는 나가기 확인창을 연다.

## 상태와 기록

- `WorldChapterBase`의 입력 잠금을 이유별로 사용한다. 나가기 확인창은 퍼즐을 중단하지 않고 일시 정지한다.
- `ChapterDirector.use_definition_flow`가 활성 비트의 조건만 읽는다. 1·2장의 기존 진행 방식은 유지한다.
- 필수 조건은 `StoryData.CHAPTER_BEATS.chapter_03`, 대사는 `ChapterThreeData`에 둔다.
- `waiting_well`, `broken_lantern`, `drag_marks`, `abandoned_sandal`, `lantern_route`, `chapter_choice`와 기존 세 선택 ID를 보존했다. 기존 에필로그 회상이 그대로 연결된다.
- 장 재방문은 도입부터 시작하고 퍼즐은 다시 풀거나 이전 완료 결과를 사용할 수 있다. 퍼즐 취소 후에는 현재 회전 상태를 유지한다.
- 성찰·퍼즐·관찰은 각 행동이 끝난 시점에 저장한다. 장 도중 나가도 관찰은 남으며, 재방문 시 장면 자체는 처음부터 재생된다.
- 2장의 질서/기도/판단 유보가 도입 독백에 반영된다. 여행자의 선택 증언은 기다림 직전 독백에서 다시 기억된다.
- 점수, 게임 오버, 믿음에 대한 정답 평가는 없다. 45초 후 문장 힌트, 90초 후 흔적 강조를 제공한다.

## 아트·소리

- `assets/art/chapter03/courtyard.png`: 2048×720 RGB, Nearest. 같은 지형 위에서 셰이더가 사암색과 남보라색 비율을 변화시킨다.
- 여섯 조사물은 독립 RGBA PNG, 표시 배율 1×. 문은 배경 개구부에 맞춰 별도 배치한다. 인물과 조사물은 발 위치로 깊이 정렬한다.
- 플레이어는 기존 방향별 2프레임을 유지하고 이 장 안에서만 68px 높이로 정규화한다. 주요 NPC는 68–70px다.
- `scripts/chapter_03_audio.gd`: 낮의 우물가 군중, 길 오른쪽 바람, 밤의 짧은 먼 발소리. 기존 5종 발소리 풀과 대사 덕킹을 재사용한다.
- 음원 출처는 기존 `assets/audio/chapter01/kenney/CREDITS.md`, `assets/audio/chapter02/CREDITS.md`를 따른다. 새로운 외부 음원은 추가하지 않았다. 등불 조사는 낮춘 금속/파편 소리, 문은 기존 나무 효과음을 재사용한다.
- 생성 원본과 프롬프트 기록: `assets/art/chapter03/GENERATION.md`. 기술적 크기/알파 정리: `tools/process_chapter03_assets.gd`.

## 검증

`tests/run_chapter03_playthrough_tests.gd`는 세 행동의 전체 진행, 서로 다른 조사 순서, 실제 E/스캐너 접근, 낮·밤 활성 상태, 선택 조사, 퍼즐 오답·취소·재개·힌트·나가기 확인 중 잠금, 출구 이동, 검증 실행 중 기존 저장 보존을 확인한다.

```
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/run_chapter03_playthrough_tests.gd
/Applications/Godot.app/Contents/MacOS/Godot --path . --script tools/capture_chapter03.gd
```

시각 검수 이미지는 `output/chapter03/`에 있다. 기본 1280×720과 큰 창에서 네이티브 16:9 화면의 UI 배치를 확인했다. Godot의 기존 종횡비 유지 설정을 따르므로 16:10 창에서도 게임 내용은 16:9로 유지된다. 기존 스토리·연출·2장 전체 진행도 함께 회귀 검증한다.

## 후속 플레이테스트 기준

이 구현은 도입부터 출구까지 완주 가능한 월드 장이다. 계획의 35–40분 분량은 아직 사람을 대상으로 측정한 결과가 아니며, 현재 구현으로 그 시간을 보장하지 않는다. 시간 늘리기용 강제 대기 없이 실제 탐색 소요 시간과 추가 서사 필요량을 플레이테스트로 결정한다. 헤드폰/스피커 최종 믹스와 목표 무힌트 해결률·길 잃는 비율도 사람을 대상으로 확인해야 한다. 기존 2프레임 플레이어의 4프레임 확장은 전 장 공통 애니메이션 작업으로 남아 있다.
