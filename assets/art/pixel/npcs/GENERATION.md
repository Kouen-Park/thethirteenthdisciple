# World NPC generation record

The exact original generation prompts and model metadata did not survive the lost working tree. Current PNGs are recovered runtime assets and are governed by `scripts/npc_cast.gd`.

Future replacements must use `ART_DIRECTION.md`, preserve each `continuity_id`, keep adult height at 66–72 pixels, use a hard transparent edge, and provide a four-frame contact/passing/contact/passing walk cycle only for characters that move on screen. Do not reuse one PNG for different identities.

Status: runtime-support; provenance incomplete; human silhouette and animation review pending.
