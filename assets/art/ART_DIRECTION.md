# The Thirteenth Disciple — 월드 아트 규격

버전 1.1 · 기준 장면: `chapter02/temple_market.png`

이 문서는 2장부터 에필로그까지 새 월드 배경과 오브젝트를 만들 때 사용하는 기준이다.
새 에셋 제작 프롬프트와 리뷰는 아래의 **고정 규칙**을 우선한다.

## 1. 화면과 픽셀 규격

- 대상 화면: PC, 1280×720, 16:9.
- 횡스크롤 월드 배경의 기본 캔버스: **2048×720 PNG, RGB, 투명도 없음**.
- 한 화면 장면은 1280×720 PNG로 제작할 수 있으나 픽셀 밀도와 카메라 각도는 동일하게 유지한다.
- 픽셀은 정사각형이며 가장자리 보간과 사진식 안티앨리어싱을 사용하지 않는다.
- 화면에서 보이는 주요 윤곽선은 대체로 2픽셀, 작은 내부 묘사는 1픽셀을 사용한다.
- Godot 텍스처 필터는 Nearest로 유지한다. 오브젝트는 목표 표시 크기로 내보내고 1× 정수 배율을 기본으로 한다.
- 배경 하나의 실사용 색상은 가능한 한 48–64색 안에서 구성하고, 불필요하게 비슷한 색을 늘리지 않는다.

## 2. 카메라와 공간

- 시점: 인물의 머리와 바닥이 함께 읽히는 **3/4 탑다운**, 약 25–30도 내려다보는 느낌.
- 세로선은 수직으로 유지하고, 바닥의 평행선은 완만하게 수렴시킨다. 과도한 등각 투시는 사용하지 않는다.
- 기본 보행 가능 영역: 화면/월드 높이의 하단 42%, 대략 `y=385…680`.
- 건축물·시장대·벽은 `y=0…385`에 두되, 하단 실루엣이 실제 충돌선과 일치해야 한다.
- 플레이어 진행은 좌→우 또는 하단→상단 한 방향을 주 동선으로 삼고, 한 화면 안에 최소 180px 폭의 빈 길을 둔다.
- 중요 출입구는 명암과 바닥선으로 읽히게 하며 배경 가장자리나 장식에 묻히지 않게 한다.

## 3. 팔레트와 광원

- 광원: 늦은 오후의 따뜻한 빛, 화면 좌상단에서 우하단으로 진행.
- 하이라이트는 노랑·살구색, 중간색은 황토·사암색, 그림자는 청보라·남색 쪽으로 hue shift한다.
- 순수 검정과 순수 흰색은 피하고, 가장 어두운 윤곽도 보랏빛 갈색을 사용한다.
- 기준 색상(근사값):

| 역할 | 색상 |
| --- | --- |
| 가장 어두운 윤곽 | `#211C28` |
| 깊은 실내 그림자 | `#302943` |
| 차가운 돌 그림자 | `#4A4058` |
| 짙은 목재 | `#5C3828` |
| 중간 목재 | `#8C5732` |
| 어두운 사암 | `#8E6C4C` |
| 중간 사암 | `#BE915B` |
| 밝은 사암 | `#E7BD72` |
| 햇빛 하이라이트 | `#FFD987` |
| 올리브 식생 | `#4B4B2D` |
| 남보라 천 포인트 | `#493B65` |

- 장면 분위기는 팔레트의 비율로 바꾼다. 긴장 장면은 청보라 그림자 비율을 늘리고, 희망 장면은 사암 하이라이트 비율을 늘린다.

## 4. 형태와 질감

- 성벽·성전: 큰 사암 덩어리를 먼저 읽히게 하고 각 돌에는 2–4단계 명암만 사용한다.
- 흙길: 큰 색면 위에 작은 돌, 바퀴 자국, 제한적인 규칙형 디더링을 배치한다. 전 영역에 무작위 노이즈를 뿌리지 않는다.
- 목재·천·도기: 재질당 하나의 분명한 색상 램프와 방향성 있는 하이라이트를 사용한다.
- 배경은 세밀하지만 플레이 대상보다 대비가 낮아야 한다. 상호작용 오브젝트 주변에는 24–40px의 시각적 여백을 둔다.
- 사진식 부드러운 그라데이션, 페인터리 브러시, 균일한 테두리 음영(pillow shading), 색 번짐을 금지한다.

## 5. 레이어와 게임플레이 규칙

- 정적 배경에는 지형·건축·멀리 있는 장식만 포함한다.
- **중요 NPC, 군중, 조사물, 문 상태, 움직일 물체는 배경에 그리지 않는다.** 별도 투명 PNG와 노드로 배치한다.
- 배경 인물이 꼭 필요하면 실루엣 수준의 먼 인물만 사용하며, 플레이 가능한 NPC보다 작고 대비가 낮아야 한다.
- 독립 오브젝트는 투명 배경, 단단한 1–2px 외곽선, 색 번짐 없는 알파 가장자리로 내보낸다.
- 캐릭터 기준 화면 높이: 일반 성인 66–72px, 어린이 52–58px. 발 위치가 월드 좌표와 깊이 정렬의 기준이다.
- 작은 조사물은 48–96px 박스, 큰 조사물은 96–160px 박스 안에서 제작한다.
- 배경의 충돌 가능 경계와 그림의 밑면은 최대 8px 이내로 일치시킨다.

현재 1장의 세 조사물은 원래의 읽기 쉬운 실루엣과 게임플레이 캔버스를 유지한 채
`tools/restyle_interactables_ch02.gd`의 결정적 팔레트·알파 정리 패스를 거친다.
새 이미지 생성이 가능해지면 이 규격과 같은 캔버스로 개별 재생성할 수 있다.

## 6. 장면 구성 체크리스트

- [ ] 2048×720 또는 승인된 1280×720 PNG인가?
- [ ] 2장과 같은 3/4 탑다운 시점인가?
- [ ] 좌상단의 따뜻한 광원과 청보라 그림자인가?
- [ ] 하단 보행 영역과 주요 동선이 즉시 읽히는가?
- [ ] 중요한 인물과 조사물이 배경에 구워져 있지 않은가?
- [ ] 캐릭터가 설 위치에 충분한 대비와 여백이 있는가?
- [ ] 붉은색/흰색 알파 테두리나 사진식 안티앨리어싱이 없는가?
- [ ] Nearest 필터 및 정수 배율로 표시되는가?
- [ ] 1280×720 카메라 좌·중·우 화면에서 잘린 랜드마크가 없는가?

## 7. 재사용용 생성 프롬프트

```text
Use case: historical-scene
Asset type: PC 2D narrative-adventure world background
Primary request: [장소와 사건을 여기에 작성]
Style reference: assets/art/chapter02/temple_market.png
Style/medium: polished high-detail pixel art; crisp square pixels; deliberate clusters; no painterly smoothing
Composition/framing: exact 2048×720 horizontal world; consistent 3/4 top-down view; walkable lower band y=385…680; clear traversal corridor
Lighting/mood: warm late-afternoon light from upper left; ochre sandstone highlights; cool indigo-violet shadows
Materials/textures: readable sandstone blocks, dusty ground, dark wood, muted indigo cloth; controlled ordered dithering
Layer constraints: static environment only; no foreground gameplay NPCs; no interactable clues baked into the background; reserve clean staging areas
Avoid: text, UI, watermark, modern objects, photorealism, smooth gradients, blurry pixels, red/white edge halos, random noise dithering, mixed pixel scales
```

## 8. 1장 리메이크 고정 사항

- 실사용 배경은 `pixel/chapter01_jerusalem_gate_world_2048.png`, **2048×720 RGB**로 고정한다.
- 2장과 동일하게 월드 원점 `(0, 0)`에서 1×로 표시하고, 1280×720 카메라가 수평으로 이동한다.
- 1장 외부 광장은 성문 밑면이 더 높게 보이는 구도이므로 보행 범위를 `y=318…680`으로 사용하며, 벽 충돌선은 `y=308`에 둔다.
- 성문은 원래 장면의 정체성을 위해 중앙 상단에 유지한다.
- 큰 길은 화면 하단에서 성문으로 이어지고, 오른쪽 샛길은 예수의 등장 동선으로 유지한다.
- 성벽·하늘·먼 도시에는 플레이어가 갈 수 없으며, 보행 영역은 길과 길가의 하단부로 한정한다.
- 종려잎·버려진 겉옷·발자국과 모든 사람은 배경에서 제거하고 기존 독립 노드를 재사용한다.
- 요나, 미리암, 군중, 예수와 나귀가 설 구역은 시각적으로 비워 둔다.
