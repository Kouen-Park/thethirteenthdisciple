# NPC 배치 기준

NPC 자산은 `scripts/npc_cast.gd`에서 장·역할·인물 연속성을 함께 관리한다.

- 상인 요나와 미리암은 1~3장에서 같은 인물로 다시 등장하므로 같은 외형을 유지한다.
- 막달라 마리아는 5장과 6장의 동일한 성경 인물이므로 같은 외형을 유지한다.
- 1장의 군중 주민은 해당 장의 선택 대화에만 사용한다.
- 2장의 성전 경비와 3장의 순례자·도망친 청년·경비의 친척은 별도 자산을 사용한다.
- 구레네 사람 시몬, 살로메와 재판장 인물들은 각자의 성경상·장면상 역할에 맞는 자산을 사용한다.
- 같은 PNG가 다른 인물을 나타내면 자동 스토리 테스트가 실패한다.

일반 주민의 말과 플레이어의 도움 행동은 창작이다. 성경 인물의 정체와 사건 결과는 본문 요약에서 분리해 제시한다.
