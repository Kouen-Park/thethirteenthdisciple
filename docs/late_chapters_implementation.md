# 4–6장과 에필로그 · 첫 월드 버전

2026-09-09. 기존 시나리오, 1–3장의 탐색/말풍선/카메라/음향 체계와 `assets/art/ART_DIRECTION.md`를 기준으로 구현했다.

## 플레이

- **4장 · 서로 다른 외침**: 식은 불자리 → 문 너머의 질문 → 군중의 단정과 외침 → 어머니의 증언. 행인의 질문은 선택 조사다. 외침이 바뀐 순서를 되짚은 뒤 본 범위만 말하기 / 침묵 / 군중에서 물러나기를 선택한다. 선택에 따라 서 있는 위치가 달라지고 군중의 소리가 잦아든 뒤 골고다로 나간다.
- **5장 · 끝까지 바라본 사람들**: 물그릇·밀려난 옷자락·말없는 목격자 조사. 길 가장자리와 담 옆의 빈틈을 찾은 뒤 물을 두기 / 곁에 서기 / 끝까지 바라보기를 선택한다. 플레이어가 실제 위치로 걸어가며, 물 선택은 그릇의 위치를 옮긴다. 사람들이 사라지고 빛이 흐려진 뒤 출구가 열린다. 처형의 직접적인 묘사는 없다.
- **6장 · 빈자리의 증언**: 시장의 소문·요나·미리암·열린 무덤 조사. 직접 관찰 / 전언 / 추론을 구분한 뒤 세 태도 중 하나를 고른다. 낯선 이가 짧게 질문하고 사라진 뒤 새벽길로 나간다. 신앙이나 선택을 정답으로 평가하지 않는다.
- **에필로그**: 1장의 관찰 및 2–6장의 저장된 선택을 회상한다. 열린 질문과 마지막 문장을 지나 크레딧으로 이동한다. 완료 상태를 기록하고 장면 선택으로 돌아갈 수 있다.

WASD/방향키 이동, E 조사, Space 대사. 퍼즐과 선택은 마우스 또는 Tab/방향키/Enter/Space. Esc는 퍼즐·선택을 먼저 닫고 탐색에서는 나가기 확인창을 연다. 퍼즐 취소 시 현재 단계와 시도 횟수가 유지된다. 힌트는 기존 45/90초 규칙이다. 필수 조사는 순서와 무관하며 관찰 완료 전 출구는 잠긴다.

## 파일과 상태

- `scripts/late_chapter_data.gd`: 후반부 월드 배치, 조사 대사, 필수 조사 목록.
- `scripts/late_world_chapter.gd`: WorldChapterBase 기반 탐색 → 퍼즐 → 선택 → 결과 → 출구.
- `story_data.gd`: 기존 퍼즐·선택 ID와 장면 경로를 보존하고 후반부 출시 잠금을 해제했다. 기존 ChapterDirector의 프로토타입 비트 대신 후반부 컨트롤러가 단계 조건을 처리한다.
- `scripts/epilogue.gd`: 저장 기반 회상과 크레딧.
- `assets/art/late_chapters/`: 네 배경과 별도 불자리. 원본과 정확한 생성 프롬프트는 `GENERATION.md` 및 `source/`에 보존했다. 내장 image_gen으로 생성했고 Godot 도구로 크기만 Nearest 정규화했다.
- 기존 NPC/그릇/천과 Kenney CC0 폴리를 재사용한다. 후반부에서 추가한 외부 음원은 없다. `assets/audio/chapter01/kenney/CREDITS.md`, `assets/audio/chapter02/CREDITS.md`를 따른다.

관찰·퍼즐·선택은 완료 직후 저장한다. 장 완료 시 다음 장을 열고 저장한다. 장 재방문은 도입부터 재생되며 저장된 이전 장 선택은 도입 독백에 반영된다. 기존 사용자의 진행도 초기화는 하지 않는다.

## 검증 및 현재 범위

`tests/run_late_chapter_playthrough_tests.gd`는 4–6장의 세 선택(9개 경로), 서로 다른 조사 순서, 실제 E 입력/스캐너 접근, 오답 재시도, 퍼즐 취소·재개, 선택 취소, 나가기 취소 후 입력 복구, 출구 페이드, 에필로그 크레딧, 검증 중 저장 보존을 확인한다. 기존 스토리·연출·2장·3장 회귀 테스트도 실행한다.

`tools/capture_late_chapters.gd`는 실제 Godot 렌더러로 좌/우 화면, 퍼즐, 선택, 에필로그와 크레딧을 `output/late_chapters/`에 캡처한다. 기본 1280×720으로 검수했다.

이번 작업은 끝까지 플레이 가능한 첫 버전이다. 후반부 퍼즐은 기존 관찰 기반 선택형 퍼즐을 월드 탐색에 연결한 형태이며 별도 드래그 퍼즐은 아니다. 군중 퇴장은 간단한 페이드다. 생성 배경의 색상 수는 48–64색 목표를 엄격히 양자화하지 않았고, 완전한 픽셀 수작업 검수·새 NPC 애니메이션·플레이 시간 측정·최종 음향 청취는 후속 다듬기 범위다.
