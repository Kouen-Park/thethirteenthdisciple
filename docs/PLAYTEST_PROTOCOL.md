# Complete prototype playtest protocol

## Fixed test environment

- Begin with a new user save.
- Test once at 1280x720 and once at 1600x900.
- Use the shipping input contract: WASD/arrows, E, Space, J, P, Esc, H.
- Do not coach the player until they explicitly say they are blocked.

## Representative flow

For every chapter, verify the complete loop:

`investigate -> open journal -> pause/resume -> save and restart -> continue`

Chapter-specific checks:

- Chapter 1: gate route, all investigations, and transition.
- Chapter 2: coin collection, table push, prayer cloth, and opened passage.
- Chapter 3: afternoon/night transition, occluded lantern beam, revealed traces,
  H hint, closed-door alignment, and all three action choices.
- Chapters 4-6: investigation order, choice cancellation, crowd exit, all nine
  persisted routes, and epilogue recollection.
